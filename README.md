# The Great Papyrus Bot V2

A multi-server Discord RPG bot with boss battles, portals, economy tools,
backpack upgrades, and the cross-server Undernet social network.

The entrypoint is `TheGreatPapyrusBot/TheGreatPapyrus/Bot.py`. Install the
dependencies with `python -m pip install -r requirements.txt`, set
`DISCORD_TOKEN`, and start the entrypoint with Python.

For a panel-by-panel hosting walkthrough, see [WISPBYTE_SETUP.md](WISPBYTE_SETUP.md).
